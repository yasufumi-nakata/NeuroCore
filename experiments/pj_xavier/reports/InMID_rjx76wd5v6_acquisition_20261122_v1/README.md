# InMIDの全公開ファイル取得・原EDF監査

**237ファイル，1,410,402,579 bytesを完全取得し，92原EDFの19.478333333時間を確認しました．** 全公開SHA256・独自SHA256とファイル不変性を照合し，元取得台帳の委譲237件のみを完了に戻しています．23 ID群に各4記録があり，完全一致EEG重複は0でした．追加モデル学習は0です．

全EDFは58信号，128Hzです．AF3/F7/F3/FC5/T7/P7/O1/O2/P8/T8/FC6/F4/F8/AF4の14本をEEGとして分離しました．時刻・counter・補間flag・電池・品質・マーカーを含む44本はEEGではありません．これらにも一律uVと書かれたヘッダ欄がありますが，単位文字列だけでEEGに数えません．

EEGのphysical/digital校正式を全サンプルへ読み取り適用し，全92件でMNEのヘッダと先頭・中央・末尾サンプルの単位変換と照合しました．これはヘッダ宣言のソフトウェア解釈の一致です．生理学的品質やハードウェア校正の独立検証を意味しません．MarkerValueIntの非ゼロへの変化は52件でしたが，時刻同期・原コードと行動の意味対応は未確認です．タイトルから意図ラベルを作っていません．

138 MATは元EDFとの派生・重複の可能性を分け，変数メタデータを調べたうえで追加原記録時間を0としています．動画や質問票等のmultimodal companionも保存していますが，EEG時間やEEGサンプルbytesへ含めません．MATの内容を実行したり，質問票の個別回答を公開したりしていません．
