## 数量を混同しないための区分

- 配布ZIP全体：**1,997,435,063 bytes**．これは取得済みEEGMMIDB全量であり，今回の派生配列とは別です．
- 以前に原ヘッダで確認した全原本：**1,526記録，48.534444時間**．
- 今回の処理で実際に復号したMI原本：**630記録，21.601944時間**．そのうち2記録は全候補窓がQC不合格となりました．
- 主入力に選ばれた対象3秒区間の合計：**7.673333時間**．この値はtrain／validation／testを含みます．
- 主入力のうち学習用：**5.299167時間**．この報告は準備済み量であり，勾配更新が実行されたことの証跡はモデル側の完了報告で確認します．

フィルタには各記録の過去の状態を使います．その履歴の長さと，モデルに渡す3秒の区間は別々に記録しました．同じ原本から作った対照・休止窓・配列を，新たに取得したEEG時間として足しません．

## 事前固定した品質条件と検証

初期100µV候補では，trainで対象72群のうち29群が全窓除外されました．そのtrain-onlyの結果を基に，scratch encoderを使う独立runでは500µVを粗大振幅の保留基準に選びました．有限値，各チャネルの母標準偏差0.01µV以上も要求します．500µVは探索的な前処理の選択であり，生理学的正常性の保証や文献の標準閾値ではありません．100µV超過の品質フラグは主入力6,058窓に保持しています．単位変更，クリッピング，スケール変更は行っていません．

最終契約はvalidation／testの信号を読む前に固定しました．保持数やモデル性能で調整しません．前向きSOSフィルタと，遅延補償をしない因果的なレート変換を使用しています．128／160Hzの両方について，未来サンプルの改変でも過去出力がbit-exactで不変であることと，prefixだけの処理との一致をテストしました．MNEとの独立単位換算，時刻境界，原本ペイロード照合，容量・期限・既存出力の保護も含め，workstationで12件が通りました．

注釈監査で保留した50記録を除外し，注釈の自動修正は0件です．除外後の今回の実入力はすべてnative160Hzでした．128Hzの処理経路は因果性テスト済みですが，保留対象を戻して入力数を増やしてはいません．
