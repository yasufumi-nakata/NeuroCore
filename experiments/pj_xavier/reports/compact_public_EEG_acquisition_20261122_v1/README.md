## ファイルと EEG payload の区別

Figshare TXT には EEG 4,520,754 個の数値があり，EEG 数値トークンそのものの UTF-8 bytes は **31,065,967** です．これは区切り文字や時刻，サンプルカウンタ，ジャイロなどを除いた実テキスト量です．float32 配列の推定量を原データの保存量として扱っていません．

Zenodo FIF の EEG 数値は 32,550,016 個，実データバッファ内の EEG 部分は **130,200,064 bytes** でした．刺激チャネルのバッファは別に **8,137,504 bytes** です．FIF のタグやメタデータは EEG payload へ加算していません．全バッファの型・サンプル境界・サイズを実ファイルで照合しました．

## ラベルと単位

Figshare は右手の kinesthetic motor imagery の力の条件 10／40／70% MVC がファイル名にあり，各条件 20 記録です．公開説明にある 1 記録 5 試行の開始予定時刻と持続時間を台帳へ保存しました．**これはファイル内の実イベント marker ではありません．** 振幅単位は公開 metadata に明記されていないため未解決とし，V への換算や生理的な QC 合否を作っていません．

サンプルカウンタは，実際には全 60 記録で 0～128，増分 +1／128→0 の増分 −128 でした．公開説明の 1～128 wrap を機械的に試した最初の flag と，この追加確認を両方保持しています．**その flag だけでサンプル欠落とは判定しません．** 時刻列は公開説明の換算で単調増加し，1/128 秒との差は最大約 78.125 µs でした．原記録や数量は補修していません．

Zenodo は実 FIF 刺激チャネルから，右手 MI，両足 MI，rest 各 **160 イベント**，合計 480 試行を確認しました．コードは公開説明の 1=trial start，2=右手，3=両足，4=rest に対応し，未知コードや 3 秒窓の記録外逸脱はありません．単位は FIF ヘッダの calibration に従う V ですが，アンプの物理校正を独立に検証した意味ではありません．

両データとも，自由な意図の文章ラベルや自律操作の正解ではありません．既存 64 ch の入力へ黙って padding したり，旧 holdout と混ぜたりしていません．14／16 ch に対応する次の固定プロトコルが必要です．

## 取得の完全性

公式 API が返したファイル数・bytes・MD5 を固定し，取得後に全ファイルの published checksum と SHA256 を照合しました．ヘッダ監査の前後にも SHA と stat を照合しています．元の大量取得台帳では，対象の未着手 68 行だけを専用 worker へ delegate し，取得・監査後に対象行だけ complete へ照合して戻しました．実行中，完了済み，lease 保持中の他の行は変更していません．

最初の試行は，旧 Zenodo 台帳の URL 由来 identity と live API の UUID 由来 identity の差を検出し，台帳変更前に停止しました．再試行では，URL，release/version，path，サイズ，checksum の一致と「旧 UUID が未記録だった」ことを確認した 8 件だけを証拠つき alias として受理しました．元台帳の identity 情報を上書きしたものではありません．実受領量は **186,109,962 bytes**，追加の学習時間は **0** です．
