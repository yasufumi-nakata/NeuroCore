# SSVEP認識課題の処理済み配布波形監査

**88ファイル／44 SET-FDT対の完全release 1,708,501,504 bytesを取得し，処理済みEEGの保存サンプル時間8.004722222時間を確認しました．** 全公開MD5・独自SHA256を検証し，元委譲88件のみを完了に戻しています．原取得512HzのBDFは含まれず，この8.00時間を「新たに取得した原raw時間」へ加算しません．

|区分|全44記録の実bytes|
|---|---:|
|64 named scalp EEG|1,475,430,400|
|8 EXG（個別の役割は未割当）|184,428,800|
|Status|23,053,600|
|SETメタデータ|25,588,704|

全記録は200Hz・1 continuous trialで，時間はN/200です．最後のサンプル時刻xmaxと記録長を混同していません．EEG payloadの完全一致重複はありません．非有限値は0ですが，信号QC合格や物理校正確認を意味しません．

[原著](https://doi.org/10.1371/journal.pone.0235309)は7.5Hz刺激の二値画像と灰色画像による認識課題です．多周波ターゲット選択のデータとは扱いません．原著は512→200Hzの処理等を説明していますが，配布SETのeventは全44件空で，明示単位欄もありません．Statusには4,530,071個の非整数サンプルと5,536,641回の値変化があり，整数へ丸めて元刺激イベントに戻すことはしません．論文のepoch・artifact除外を現物へ推定適用することもしていません．

今回の監査は保存済みサンプル・bytes・形式の確認です．教師ラベル，実刺激時刻，振幅校正，online因果性は未確認です．同一IDの4ブロックを分割間に散らさず，単位・QC・参加者分割を固定する新契約ができるまで既存モデルに混ぜません．追加学習時間は0です．

初版parserはMATLABの空type配列を文字列へ変換して誤拒否しました．失敗ログを保全し，空文字または実際に要素0の配列のみを受容するv2と回帰テストで監査を完了しています．原波形やメタデータの編集はありません．
