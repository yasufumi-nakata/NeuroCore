# Brainstorm聴覚EEGの原記録・全アーカイブ監査

**完全ZIP 280,230,370 bytesを取得し，10原BrainVision記録から0.469455556時間を確認しました．** 公開MD5・独自SHA256，全3,002非ディレクトリmemberのCRC・SHA256を照合し，元取得台帳の委譲1件のみを完了へ戻しています．新規モデル学習は0です．

|区分|実測bytes|
|---|---:|
|62 EEG候補の原int16サンプル|209,564,960|
|2補助／役割未確定信号|6,760,160|
|研究記録のヘッダ・マーカー|177,833|
|同梱ソフトウェア・その他|158,922,412|
|全非ディレクトリmember展開サイズ|375,425,365|

全10記録は64信号・1,000Hzです．原ヘッダの19番IO・20番ECGをそのまま保持し，残り62本を保守的なEEG候補としています．著者の変換スクリプトは全64本へE1〜E64のmontageを当てますが，それだけで元2本の役割を確定しません．[論文](https://doi.org/10.3389/fnins.2018.00309)のcapと眼下電極の説明との対応は，将来の学習前に確認が必要です．

原ヘッダはint16あたり0.1µVを宣言し，全10件でMNEヘッダと先頭・中央・末尾の校正値を照合しました．これはソフトウェアによる宣言単位の解釈の一致で，アンプの独立校正・信号QC合格ではありません．原マーカー1,820件は境界内でしたが，音の実発生時刻や意図のgoldとは扱いません．イベント名や原波形の編集は0です．

EEGLAB等の同梱ソフトウェアには別の例示EEGもあります．研究の10記録へ加算せず，配布全体のbytesとしてのみ保持しています．監査では1組の小さなtripletだけを一時読取りし，巨大な一括展開は行っていません．実記録時間はN/1000，チャンネル数やソフト例示数による乗算はありません．
