## 物理単位と固定処理

元 GDF の ordered 27 EEG，native 512 Hz を使用し，3 EOG と 2 EMG は入力へ加えていません．元 file SHA，元 scalar payload SHA，header calibration SHA を照合したうえで，sample-major little-endian float64 の physical-V identity を別に記録しました．

digital endpoints を float64 へ変換してから gain を計算し，`scalar * gain + offset` の affine 形式で校正します．大きな digital endpoint を先に scalar から引く処理を避け，各記録の先頭・中央・末尾の全 27 EEG を MNE と独立照合しました．今回の train 検査では校正不一致の quarantine は 0 でした．これは配布 header と parser の整合確認であり，実機 amplifier の校正まで独立検証した意味ではありません．

処理条件は現物の QC 前に固定しています．

- Butterworth N=4 の 3–40 Hz bandpass，forward-only SOS，記録ごとの zero initial state．追加 LP80 は使用しません．
- 2 秒 warmup，native の 1 sample 遅延を持つ補間で 200 Hz へ変換．将来 sample は参照しません．
- 非重複 3 秒窓，shape `[N,27,3,200]`，float32，単位 `V_x_1e4`．
- native 最大絶対値 0.1 V，処理後最大 peak 100 µV，最小 channel 標準偏差 0.01 µV．倍率の推測補正・clipping・QC 緩和は行いません．

[準備処理](../../next_multichannel/prepare_smac_bci8089820.py)に実装と identity scope を記録しています．元 GDF の event timebase と配布前処理の因果性は未確認であり，online harness を許可していません．

## 解釈の範囲

学習量と対象 source は拡大しましたが，旧 domain の検証誤差は微小に増えました．新 BCI validation での改善は，別の事前固定診断で確認した範囲の結果です．元の test，生物学的独立性の追加確認，行動 decode，自由意図，EEG→LLM，実 OS 操作の成功率を示すものではありません．

元 file，scalar payload，校正後 physical-V の既知 identity と元 group／must-link を継承しています．未公開の参加者同一性や変換された cross-release alias を全て否定したとは扱いません．元の単位・因果性・event timebase の未確認事項は，学習時間の増加によって解消されたことにはしません．
