# pj-xavierとNeuroCoreの位置付け

**pj-xavier（Project Xavier）は，NeuroCoreのAIを研究開発するプロジェクトです．**

この定義は，2026年11月21日にプロジェクトオーナーが明示した位置付けに基づきます．NeuroCore向けAIを実現するために，データ，モデル，評価，連携の研究開発を進めます．

## プロジェクトの目的と個別研究課題

- EEGの表現学習・基盤モデルの検討と評価．
- EEGと画面・操作ログなどを扱うマルチモーダル統合．
- ユーザーの高次の意図や委任意図を推定する手法の研究．
- 推定結果をAIエージェントへ接続する方法と，その追加価値の評価．
- 上記に必要な学習・評価データの選定，収録，同期，品質確認．

これらはNeuroCoreのAIを開発するための個別研究課題です．PC操作・Computer Useは初期の検証・応用対象として扱います．プロジェクト全体の目的を，PC操作だけに限定しません．

## このリポジトリが担う範囲

このNeuroCoreリポジトリは，信号の正規化と検証，前処理，ストリーミング，設定，intentの検証，action envelopeの生成などのランタイム層を実装します．EEGデータの取得・管理・検証もその一部です．その機能だけでNeuroCore全体を定義しません．

pj-xavierで研究開発するモデルの学習コード，評価成果物，モデル重みは，core runtimeとは分けて管理します．外部デコーダが返すintentをNeuroCoreのランタイムへ接続する設計です．このパッケージ境界と，pj-xavierがNeuroCoreのAIを開発するというプロジェクト上の役割は両立します．

## 関連するデータ目録

EEG-datasetは，学習・評価に使う公開EEG資料の探索と検証を支える目録です．データ目録，データ取得・前処理，AIモデル開発，ランタイム実装は，それぞれの役割と成果を区別します．目録への掲載だけでは，波形取得済み，利用条件確認済み，学習可能，モデル実装済みとは判断しません．

## 開発状況の表現

この文書はプロジェクトの目的と役割を定義します．各モデルの実装・学習・実機評価や性能が完成したという報告ではありません．既存の技術的制約，データ利用条件，評価結果，未検証事項は各資料の記載に従います．

今後の資料では，まず「pj-xavierはNeuroCoreのAIを研究開発するプロジェクト」と示し，そのうえで個別研究課題と現在の実装範囲を説明します．
