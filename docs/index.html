NeuroCore

pj-xavier（Project Xavier）は，NeuroCoreのAIを研究開発するプロジェクトです． このサイトでは，EEG decoderのintentをマウス，キーボード，AIエージェント向けのaction envelopeへ変換するNeuroCoreのランタイム層を案内します．

AIモデルとdecoder weightsはcore runtimeの外で管理します．pj-xavierの位置付けと各層の役割

チュートリアルを開く 配布物を見る 運用手順
1. EEG frame samples、channels、timebase、events、provenance を `NeuroFrame` にそろえます。
2. Deterministic pipeline validation、resampling、bandpass、reference、features を report 付きで実行します。
3. External decoder NeuroCore向けAIはpj-xavierで研究開発し，モデル重みをcore runtimeから分離して接続します．
4. Safe action envelope confidence、rate limit、emergency stop、agent payload guard を通してから dry-run 記録します。
