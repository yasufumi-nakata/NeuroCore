EEG to control runtime

NeuroCore

EEG decoder が出した intent を、マウス、キーボード、AI エージェント向けの安全な action envelope に変換します。 decoder weights はこの package に入れず、runtime、設定、監査、自己テストを分離して扱います。

チュートリアルを開く 配布物を見る 運用手順
1. EEG frame samples、channels、timebase、events、provenance を `NeuroFrame` にそろえます。
2. Deterministic pipeline validation、resampling、bandpass、reference、features を report 付きで実行します。
3. External decoder intent 推定と重みづけは別システムです。NeuroCore は重みを持ちません。
4. Safe action envelope confidence、rate limit、emergency stop、agent payload guard を通してから dry-run 記録します。
