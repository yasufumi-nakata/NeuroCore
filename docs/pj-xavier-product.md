# NeuroCore クライアント 0.3.0（PJ-Xavier ソフトウェア試験版）

脳波（EEG）と画面画像をSMAC上の登録済みモデルに送信するローカルUIです．日本語画面，モデルのロード・アンロード，EEG予測，画面取得，操作提案，ユーザーが承認した単一操作の適用，停止，履歴を提供します．

**科学的Lv.8の成立・EEG寄与・第三者評価は未確認です．** この配布物は製品としての接続・操作機構の試験版であり，医療用途や無人操作に使わないでください．モデル重み，生のEEG個票，データセット，認証情報は含めていません．

## 使い方

Windows（Python 3.10以降・OpenSSH・VPNが必要）：

```powershell
.\Install-NeuroCore.ps1
.\Start-NeuroCore.ps1 -SshHost smac20 -SshUser <SSHユーザー>
```

macOS（Python 3.10以降・SSH・VPNが必要）：

```sh
sh Install-NeuroCore.sh
sh Start-NeuroCore.sh smac20 <SSHユーザー>
```

ブラウザで `http://127.0.0.1:8788` を開きます．SMAC20にSSHで接続するためのホスト鍵は事前に別経路で検証し，各PCに本人のSSH鍵を設定してください．SSHパスワード・秘密鍵はこの配布物では取得・保存しません．接続できない場合は，VPN，SSHの鍵認証，SMAC20のモデルAPI（127.0.0.1:8011）の順に確認してください．

モデルを利用するには画面からモデルを明示的に読み込む必要があります．`unloaded` はモデル未ロードの状態であり，API停止を意味しません．

- ローカルアプリは `127.0.0.1:8788` のみに束縛されます．GPU推論サーバーはSMAC20上のループバックで稼働し，ローカルSSHポート18010経由でアクセスします．
- 入力波形の契約は整形済み30チャネル×300サンプル，200Hz，µVです．画像入力とアクション履歴は別途送信します．
- GUI操作はOS側の画面収録・アクセシビリティ権限が必要です．操作は毎回ユーザー確認を経て1件のみ実施します．
- `python scripts/client_selfcheck.py` で健康状態とUI配信を確認できます（モデル推論もOS操作も実行しません）．

署名済みインストーラーではないため，内容・依存関係の確認後に導入してください．

## 配布・稼働確認
本リポジトリはソースコードと日本語UIのビルド済み静的アセットを収録します．SMAC20のモデル基盤重み，追加重み，モデルレジストリ，計測データ，認証情報は含まれません．モデルサーバーの導入とホスト鍵登録は管理者がローカルで行う必要があります．

2026-11-27の実機確認では，Apple M2 Maxでの合成波形予測および画面画像に基づく操作**提案**を確認しました．独立被験者での性能検証および実画面操作は未実施です．
