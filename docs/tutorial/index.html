NeuroCore tutorial

この tutorial は、EEG device をまだ接続していない状態でも runtime が壊れていないかを確認できる最短経路です。 NeuroCore は decoder weights を持たないため、ここでは synthetic EEG と JSON intent fixture を使います。

1. Install

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev,server,io]"

2. Run the self-test

neurocore self-test --json

self-test は synthetic EEG の正常経路に加えて、NaN、invalid passband、low confidence、emergency stop、 agent payload guard のような破綻ケースを確認します。

3. Process a CSV fixture

neurocore run-csv samples/synthetic_eeg.csv --sampling-rate 250 --json
neurocore run-file samples/synthetic_eeg.csv --sampling-rate 250 --json

CSV は samples x channels の形です。`run-file` は CSV / NumPy / MNE 対応形式 / XDF / MAT を `NeuroFrame` へ正規化してから pipeline へ渡します。 CSV にラベル列や ID 列のような非数値列が混ざる場合は、数値列だけを channel matrix として読みます。 MNE 経由では EDF/BDF、BrainVision、EEGLAB、FIF、CNT/GDF、EGI/MFF、eXimia、Nicolet、Persyst、MEF3 形式を入口にできます。 NWB は PyNWB 経由で `ElectricalSeries` を読み、DANDI 由来の ecephys assets を `NeuroFrame` へ変換する入口として扱います。

4. Inspect an EEG-DATA inventory

neurocore dataset-inventory ../EEG-DATA/eeg_dataset_summary_ja.csv --json
neurocore dataset-acquisition-plan ../EEG-DATA/eeg_dataset_summary_ja.csv --json
neurocore dataset-resolve-files ../EEG-DATA/eeg_dataset_summary_ja.csv --limit 10 --json
neurocore dataset-resolve-files ../EEG-DATA/eeg_dataset_summary_ja.csv --provider openneuro --provider dandi --provider kaggle --provider nemar --limit 5 --json
python scripts/verify_dataset_loading.py --inventory ../EEG-DATA/eeg_dataset_summary_ja.csv
python scripts/verify_dataset_acquisition.py --inventory ../EEG-DATA/eeg_dataset_summary_ja.csv
python scripts/verify_dataset_acquisition.py --inventory ../EEG-DATA/eeg_dataset_summary_ja.csv --resolve-remote-files --resolve-limit 10
python scripts/verify_dataset_acquisition.py --inventory ../EEG-DATA/eeg_dataset_summary_ja.csv --cache-root private/raw-cache --max-local-files-per-record 0 --max-loads 0 --load-local

EEG-DATA checkout は raw EEG そのものではなく、公開 dataset の metadata 目録として扱います。 目録 report は EDF/BDF、BrainVision、EEGLAB `.set`、FIF、CNT/GDF、EGI/MFF、eXimia、Nicolet、Persyst、MEF3、NWB、BIDS 風 directory、XDF、MAT、NumPy、CSV などの loader coverage も返します。 acquisition report は配布元ごとに API 取得、provider CLI、アカウント必須、手動確認を分け、公開 API や file index で解決できるものは remote file candidate として `download_then_load` / `download_extract_then_scan` / `metadata_or_manual_review` に分類します。 対応 resolver は Zenodo、Figshare、OSF、Dataverse、Dryad、Mendeley、OpenNeuro、GitHub、Hugging Face、PhysioNet、DANDI、Gin、Kaggle、NEMAR、DOI landing delegation です。 archive を materialize した場合は zip/tar を安全に展開し、展開後の対応 raw file を再スキャンして loader に渡します。

5. Route decoded intents

neurocore route-intent select --confidence 0.92 --json
neurocore simulate-intents samples/intent_commands.json --json

`ControlRouter` は外部 decoder が決めた intent を検証し、mouse、keyboard、agent の action envelope へ変換します。 実際の OS 操作や agent 実行は、この core package では行いません。

6. Start the local API and settings UI

PYTHONPATH=backend uvicorn neurocore.api:app --reload --port 8010
cd frontend
npm install
npm run dev -- --host 127.0.0.1 --port 5174

設定画面では device、signal plan、safety policy、routing、self-test を確認できます。 API が起動していない場合も UI は表示されますが、実運用前の検証では API self-test を通してください。

7. Before adding a real EEG device

  • decoder weights、training checkpoints、個人 EEG raw data はこの repository に入れません。
  • device loader は timestamp、sampling rate、channel labels、unit を明示して `NeuroFrame` を作ります。
  • OS 操作と AI agent 実行は、別プロセスの permissioned service で human-arm と audit をかけます。
  • 新しい route や payload を足すときは、allowed path と blocked path の両方を test に入れます。
運用メモ: GitHub Actions は Python tests、frontend build、Pages、package artifact、CodeQL、Scorecard、Dependency Review を分けて実行します。 issue や alert が出た場合は、まず該当 workflow と security alert を確認し、再現できる最小テストを追加してから修正します。
NeuroCore は decoder weights を含まない EEG control runtime です。OS 操作と agent 実行は外部の permissioned service が担当します。
